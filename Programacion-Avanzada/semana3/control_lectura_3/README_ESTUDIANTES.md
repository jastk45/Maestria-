# Control de lectura 3

Actividad individual de aproximadamente 20 minutos. Lea el material previo
antes de la evaluación; el tiempo de lectura no forma parte de los 20 minutos.

## Qué abrir

- `Control_Lectura_3_Enunciado.pdf`: condiciones y tareas.
- `Control_Lectura_3_Starter.ipynb`: opción principal si ya dispone de Jupyter.
- `Control_Lectura_3_Starter.py`: alternativa sin Jupyter; usa solo Python 3.

Elija una opción. No tiene que completar ambos archivos. Prepare y compruebe
el entorno antes de clase. No se necesitan NumPy, PyTorch ni conexión de red
para ejecutar el experimento; no instale paquetes durante el control.

## Notebook

Abra el archivo con el entorno Jupyter que utiliza en el curso. Escriba su
nombre, responda P0 antes de ejecutar y complete la única expresión pendiente.
Ejecute las celdas en orden, responda P1 a P3, reinicie el kernel, ejecute todo
y guarde. Las tablas quedan dentro del notebook.

## Script alternativo

Complete los mismos espacios y escriba las respuestas como comentarios bajo
P0 a P3. Desde una terminal en la carpeta del archivo, ejecute:

```bash
python Control_Lectura_3_Starter.py
```

Si su equipo utiliza `python3` o el lanzador `py`, use ese comando para Python 3.
El script imprime las tablas y genera el CSV en la carpeta de trabajo.

## Entrega

Entregue su notebook guardado o su script, junto con `resultados_control_3.csv`.
El archivo debe contener nombre, función y respuestas P0 a P3. No cambie la
función de prueba, los candidatos, el punto ni los tres pasos indicados.

El starter intacto muestra PENDIENTE y no genera un CSV nuevo. No hay una
solución que se ejecute automáticamente. Un CSV anterior no acredita una
ejecución incompleta; entregue únicamente resultados del intento actual.
Si no termina, conserve su trabajo parcial e indique qué falta.

La existencia del CSV no certifica corrección. El docente revisará el método,
los resultados y la calidad de las explicaciones. Conserve su predicción
inicial aunque los resultados le hagan cambiar de opinión.
